# Robinhood Chain

Each agent uses its EVM address on Robinhood Chain testnet (chain 46630). Agents read their test ETH and send to an address you approve. Every send waits for your Confirm. Test funds only.

## What agents can do

- Its Robinhood Chain testnet address and ETH balance
- Send test ETH, after you confirm
- Tokenized stocks (coming soon)
- Mainnet (coming soon)

Chains: Robinhood Chain testnet. Website: https://robinhood.com. Docs: https://docs.robinhood.com/chain.

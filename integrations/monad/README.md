# Monad

Each agent uses its EVM address on Monad testnet (chain 10143). Agents read their MON balance and send test MON or USDC to an address you approve. Every send waits for your Confirm. Test funds only.

## What agents can do

- Its Monad testnet address and MON balance
- Send test MON or USDC, after you confirm
- Swaps on Kuru
- Mainnet (coming soon)

Chains: Monad testnet. Website: https://www.monad.xyz. Docs: https://docs.monad.xyz.

# Base

Each agent has its own address on Base. Agents read their Base Sepolia ETH and test USDC and send to an address you approve. Every send waits for your Confirm. Test funds only.

## What agents can do

- Its Base Sepolia address and balances
- Send test ETH or USDC, after you confirm
- Swaps through Uniswap
- Mainnet (coming soon)

Chains: Base Sepolia. Website: https://base.org. Docs: https://docs.base.org.

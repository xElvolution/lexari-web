# Ethereum

Each agent has its own Ethereum address. Agents read their Sepolia ETH and test USDC and send to an address you approve. Every send waits for your Confirm. Test funds only.

## What agents can do

- Its Sepolia address and balances
- Send test ETH or USDC, after you confirm
- Swaps through Uniswap
- Mainnet (coming soon)

Chains: Sepolia. Website: https://ethereum.org. Docs: https://ethereum.org/developers.

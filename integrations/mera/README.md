# Mera

Mera derives keys from a passkey (WebAuthn PRF), with no seed phrase and nothing secret stored. Your passkey signs you in to Lexari and derives a separate EVM key for each agent, so one Face ID or Touch ID covers all of them. Add it in Settings, Security.

## What agents can do

- Passkey sign-in
- A separate key for each agent from one passkey
- Same keys on every device your passkey syncs to

Chains: Monad, Solana. Website: https://mera.category.xyz. Docs: https://mera.category.xyz.

# Alchemy

Alchemy powers Lexari's Monad connection (RPC) and its Token API: your agent can list every token it or any address holds on Monad, with names and amounts. Read only; it never moves money.

## What agents can do

- Monad RPC for every agent
- Token balances and metadata

Chains: Monad testnet. Website: https://www.alchemy.com. Docs: https://www.alchemy.com/docs.

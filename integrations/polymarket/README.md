# Polymarket

Your agents search Polymarket, read live odds and each outcome's order book price. Polymarket only trades with real USDC on Polygon (there is no test order book), so placing orders stays off until it's switched on for your account. When it is on, every order waits for your Confirm inside your per-trade and daily limits.

## What agents can do

- Trending markets and search
- Live odds and order book prices
- Buy an outcome on Polygon mainnet, after you confirm (coming soon)

Chains: Polygon. Website: https://polymarket.com. Docs: https://docs.polymarket.com.

# Arbitrum

Each agent uses its EVM address on Arbitrum Sepolia. Agents read their test ETH and USDC and send to an address you approve. Every send waits for your Confirm. Test funds only.

## What agents can do

- Its Arbitrum Sepolia address and balances
- Send test ETH or USDC, after you confirm
- Swaps through Uniswap
- Mainnet (coming soon)

Chains: Arbitrum Sepolia. Website: https://arbitrum.io. Docs: https://docs.arbitrum.io.

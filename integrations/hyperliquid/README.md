# Hyperliquid

Each agent trades from its own Hyperliquid testnet account through an API wallet: a separate key that can place and cancel orders but can never withdraw or move funds. Agents read prices, positions and open orders, and every order waits for your Confirm inside your per-trade and daily limits. Test USDC only.

## What agents can do

- Live prices, positions and open orders
- Market and limit orders, after you confirm
- Trade-only API wallet, no withdrawals
- Mainnet (coming soon)

Chains: Hyperliquid testnet. Website: https://hyperliquid.xyz. Docs: https://hyperliquid.gitbook.io/hyperliquid-docs.

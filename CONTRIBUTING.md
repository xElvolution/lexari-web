# Contributing

Thanks for wanting to help with Lexari. Bug reports, ideas, fixes and docs improvements are all welcome, big or small.

## Issues

- Search the open issues first in case someone already raised it.
- For a bug, tell us what you did, what you expected and what happened instead. Screenshots, browser or device, and the page URL help a lot.
- For an idea, describe the problem you want solved before the solution you have in mind.
- Please don't post secrets, API keys, wallet seed phrases or private keys in an issue. If you found a security problem, open an issue that just asks us to get in touch, and leave the details out.

## Pull requests

1. Fork the repository. The fork is only for preparing your pull request; see [LICENSE](LICENSE).
2. Make a branch for your change and keep it focused on one thing.
3. Test what you changed and describe it clearly in the pull request: what it does, why, and how you checked it.
4. Open the pull request against `main`. We'll review it, may ask for changes, and merge it when it's ready.

Small fixes like typos can go straight to a pull request. For anything larger, open an issue first so we can agree on the approach before you spend time on it.
